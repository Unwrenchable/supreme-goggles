# Contributing to AtomicFizzCaps Universal Naming Service

Thank you for your interest in contributing! 🎉

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/supreme-goggles.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature-name`
5. Make your changes
6. Test: `npm run build` and `npm run dev`
7. Commit: `git commit -m "Add your feature"`
8. Push: `git push origin feature/your-feature-name`
9. Create a Pull Request

## Development Guidelines

- **Code Style:** Follow existing patterns, use TypeScript
- **Testing:** Ensure `npm run build` succeeds
- **Documentation:** Update README if adding features
- **Commits:** Use clear, descriptive commit messages
